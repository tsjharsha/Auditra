# Auditra Evaluation

Evaluation remains independent from controller execution. The controller receives visible source records only; the evaluator receives hidden ground truth after a run completes.

## Metrics

Controller and evaluation outputs include:

- accuracy, precision, recall, F1
- false-positive and false-negative rates
- match, exception, unresolved, escalation, and automatic-resolution rates
- throughput
- median, p95, and p99 latency
- AI investigation count
- LLM calls
- agent tool calls
- estimated AI cost
- average risk score
- financial amount correctly reconciled
- financial amount incorrectly classified
- financial impact of errors
- confusion matrix
- class-level precision, recall and F1
- failure taxonomy

## Commands

Run the frozen demo:

```powershell
python scripts/world_demo.py --seed 42
```

Run the held-out benchmark:

```powershell
python scripts/phase_c_heldout.py --records-per-slice 200 --seed 42000
```

Run the scale benchmark:

```powershell
python scripts/phase_c_benchmark.py --counts 100 500 1000 5000 10000 50000 --mode MIXED --seed 42 --output phase_c_benchmark.json
```

Run concurrency and demo reliability:

```powershell
python scripts/phase_c_concurrency.py --levels 1 5 10 25 50 --records 120 --seed 9000
python scripts/phase_c_demo_reliability.py --runs 10 --seed 42 --records 500
```

Measure Phase A AI value on a prompt-built financial world:

```powershell
python scripts/ai_value_benchmark.py --records 1000 --seed 42
```

Run a compact demo artifact export:

```powershell
python scripts/demo_run.py --mode MIXED --records 1000 --seed 42
```

Write the full run only when needed for debugging:

```powershell
python scripts/demo_run.py --mode MIXED --records 1000 --seed 42 --write-full-run
```

## Failure Taxonomy

Failures are grouped as:

- `OVER_ESCALATION`
- `MISSED_CONFLICT`
- `FALSE_EXCEPTION`
- `MISSED_EXCEPTION`
- `CLASSIFICATION_ERROR`

These labels are generated by the evaluator and are not exposed to the controller during reconciliation.
